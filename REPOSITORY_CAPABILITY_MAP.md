Produced by direct repository inspection (file reads, grep-based cross-reference checks, script execution) on 2026-08-22, not by re-describing the README. Method: every "Test coverage" and "Current status" cell below is backed by either (a) a command actually run against the repo (cited), or (b) a direct reading of the cited file.
