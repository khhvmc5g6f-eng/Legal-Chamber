# legal-academic

## Establish the actual rubric before writing

University, programme, level, module, assignment type, word count, referencing system, and (if available) the actual marking rubric or learning outcomes. Check `../../rubrics/` for a real file matching the situation before doing anything else - `level7-distinction-standard.md` exists for Bachelor's (Hons), Integrated Master's, and taught postgraduate (Level 7) degree-classification bands, sourced from a real UK institution whose name is deliberately withheld (see that file's "Provenance" section), and is explicit about what it doesn't cover (qualitative descriptors, and any programme its own scope section excludes - check that section before assuming it applies). `../../rubrics/README.md` explains why this repository does not ship invented institutional rubrics for anything not yet supplied this way - never present a made-up grade descriptor as if it were a real institution's rubric, and never extend a real institution's *numeric* classification bands into invented *qualitative* descriptor language just because the bands themselves are verified. If no real rubric is available for the situation at hand, fall back to the general standard in `../../docs/OPERATING_RULES.md` and say plainly that it's a general standard, not a specific institution's own rubric.

**Standing target: Level 7 Distinction (70% and above) or higher**, per `../../rubrics/level7-distinction-standard.md`'s own "Target standard" section - this is the default quality bar for academic work produced here, not merely a pass. Hold every draft to it unless the user asks for a different bar for a specific piece of work.

## Academic integrity first

Before drafting anything for an assessed piece of work, check (by asking, if not already known) what that institution's AI-assistance policy actually permits. Where prohibited or unclear, switch modes: explain, give feedback, ask Socratic questions, coach research - do not produce assessable prose the student would submit as their own unaided work. See `../../docs/OPERATING_RULES.md` "academic integrity."

## What high-quality academic legal work actually looks like

Not flowery language. Conceptual precision, comprehensive issue recognition, authoritative (checked) research, genuine synthesis across sources, engagement with competing views, independent judgment, disciplined argument, a justified conclusion. Apply the same citation verification standard as any other Legal Chambers output - an academic citation that turns out to be fabricated is a hard failure here exactly as it is in litigation work.

## Marking panel (if a self-assessment or feedback pass is wanted)

Independent lenses, not one holistic score: knowledge/issues, analysis/application, research/authority, critical evaluation, structure/presentation - plus a sceptical "external examiner" pass that pushes back on grade inflation. Score against the standing Distinction-level target above, not a generic "is this good" impression - if the panel's honest assessment lands below that band, say so plainly and identify what specifically would need to improve to close the gap, rather than rounding up. Run each lens (and the external-examiner pass) as `../../agents/academic/ROLE.md` in a fresh, isolated context per lens - a panel scored by one shared context re-using its own earlier reasoning isn't independent.
