# Courts

Cross-jurisdiction court-rule notes and filing-format checklists that don't belong inside a single jurisdiction pack. In this build, court hierarchy and headline procedural-instrument names live inside each `../jurisdictions/<slug>/README.md` instead - this directory is a placeholder for when a specific court (rather than a whole jurisdiction) needs its own deeper pack, e.g. a specific court's local rules, standing orders, or bundle/formatting requirements.

## Status

**EXPERIMENTAL.** No court-specific pack has been built yet in this version. See `../docs/HONEST_STATUS.md`.

## What a court-specific pack should contain, when one is added

- The court's exact name, level, and jurisdiction it sits in (link back to the relevant `../jurisdictions/<slug>/README.md`).
- Filing format requirements: page/word limits, fonts, margins, pagination, bundle/exhibit conventions.
- Local rules or standing orders, distinguished from the general procedural rules of the jurisdiction, with a primary-source link and check date.
- A filing-preflight checklist matching `../docs/QUALITY_GATES.md` Gate 13.

## Contributing one

Follow `../GOVERNANCE.md`'s sourcing requirements - a primary source, a check date, and a named reviewer per claim.
