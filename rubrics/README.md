# Rubrics

Academic marking rubrics used by `../skills/legal-academic/SKILL.md` and `../agents/academic/ROLE.md`.

## Status

**Deliberately empty of institutional content.** No specific university's rubric is invented here - see `../docs/OPERATING_RULES.md` Part LXXXVII: "do not invent institutional rubrics." A rubric file can only be added once someone actually supplies (or points to) the real, current rubric from a named institution.

## Rubric file format, when one is added

```
Institution
Faculty
Programme
Assessment type
Official source (link or document reference)
Version/date
Grade descriptor
Last verified
```

## Fallback

Absent a real institutional rubric, `../skills/legal-academic/SKILL.md` uses the general standard in `../docs/OPERATING_RULES.md` (knowledge, issue identification, research, authority, analysis, application, synthesis, critical evaluation, counterargument, originality, structure, communication, citation, presentation) and says plainly that it is a general standard, not the institution's own.
